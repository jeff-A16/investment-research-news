# 一手研究链

- 黄金：TIPS实际利率/美元/利率预期 → ETF份额及持仓、央行购金 → COT → 同单位/币种/时段的境内外价差与实物供需；关联按条件检验。
- 债券/转债：政策与资金利率 → 曲线/信用利差 → 发行/托管 → 纯债价值、转股溢价、下修/赎回/回售/信用事件；条款回查发行人。
- 基金：法律文件/公告 → 净值、费率、基准、经理、规模与流动性 → 持仓/风格、收益来源、回撤和风险暴露；统一分红、费用和币种。
- 流动性：央行操作规模/利率/期限及到期 → 净投放和回购；海外结合SOMA、SOFR/回购/逆回购、TGA、货基，注明推断条件。
- 企业/产业：财报、业绩会、招股/募集文件 → 收入利润、现金流、资本开支与到期债务 → 订单/产销/库存、行业及海关验证。
- FOMC决议/纪要/官员讲话不同；COT/13F分统计日与公布日，13F不完整。ETF成交额/规模增长不能当净现金流，实物申赎另解释。
- 估值/指数核对历史成分、编制及价格/全收益口径；FRED回溯原发布机构，ALFRED等历史版本避免前视及幸存者偏差。
- WGC/LBMA/协会属行业来源；经理/管理层意见不等于正式事实；FedWatch须具体会议/区间/方法，概率不是官方承诺。

子项实测及未完成项见component-checks.json；状态只证明所列样本/公开范围，不推成全机构、全团队或全天覆盖。
